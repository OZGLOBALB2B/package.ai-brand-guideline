# Package.ai — Brand Guidelines

Static brand-guidelines site (single `index.html`, no build step) with side navigation.
Content source: Figma "Brand Guideline OZ Update Nov 26" (LPrVu2q9rSfa4uVNeSPAbO).

Downloads (SVG / PNG / ZIP / color tokens) are generated in the browser from the official vector files embedded in the page.

Deploy: import this repo into Vercel as a static project (Framework: Other, no build command, output = root).
